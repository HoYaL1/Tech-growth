# 《DAGUARD: 联邦学习下的分布式后门攻击防御方案》阅读记录

## 背景

​	联邦学习虽然能够避免直接共享用户数据，但客户端上传的模型更新仍可能被恶意利用。尤其是分布式后门攻击中，多个恶意客户端可以协同注入后门，使攻击更加隐蔽，传统防御方法难以有效检测。同时，攻击者还可以通过控制模型更新的方向和幅度来逃避现有的聚类、裁剪等防御。因此，论文针对分布式后门攻击难检测、难防御的问题，提出了 DAGUARD，通过结合 Tern Grad、Adapt DBSCAN、自适应裁剪和自适应加噪，从多个方面提高联邦学习的后门防御能力。

## 相关知识

​	**基于密度的聚类算法**中,当区域内点的密度大于最小密度值时,该区域被称为密集区域或密度相连区域。由于基于密度的聚类算法基于密集连通性扩展集群,该类算法可以找到任意形状的集群。

​	**DBSCAN** 是 基 于 密 度 的 带 噪 声 应 用 空 间 聚 类,其根据密度的方差区分高维数据库的噪声。 DBSCAN 根据预先设定的超参数领域半径 Eps 和簇 内最小样本数目 MinPts。将数据点分为核心点,边界点以及噪声点。当某个数据点在 Eps 半径内至少包 含了 MinPts 个数据点时,该数据点为**核心点**;当某 个数据点的 Eps 半径内包含的数据点少于 MinPts 个 且该数据点在其他核心点的领域半径内,则该数据点 为**边界点**;既不是核心点也不是边界点的则是**噪声点**。

​	**TernGrad** 是一种三元梯度量化方法，原本用于提高联邦学习中的通信效率。DAGUARD 将其用于客户端本地梯度更新：对神经网络各层的梯度进行 Ternarize 转换，通过每层绝对值最大的梯度确定缩放因子，从而保留重要的梯度更新信息，同时避免直接上传完整梯度。这种方式能够降低服务器通过完整梯度进行推理攻击的风险，并减弱攻击者对局部梯度进行精细调整所造成的后门攻击影响。



## 防御策略

#### TernGrad 局部更新

​	首先在客户端本地训练完成后，使用 TernGrad 对梯度进行三元量化处理。具体来说，对神经网络的每一层梯度进行 Ternarize 转换，并根据每层梯度中的最大值确定缩放因子，在尽量保留重要梯度更新信息的同时，避免直接暴露完整的梯度信息。这样既可以降低服务器利用完整梯度进行推理攻击的风险，也能够减弱攻击者对局部梯度进行调整所造成的后门攻击影响

#### 自适应DBSCAN（AdaptDBSCAN）

​	由于大多数恶意梯度相比良性梯度存在较大的**角度偏离**，聚类方法成为剔除恶意攻击的有效手段。现有的方法要么在非独立同分布下会错删良性梯度要么容易将良性模型与恶意模型错误划入同一簇中。FLAME方案使用的HDBSCAN虽然基于余弦距离聚类，但当恶意梯度临界于良性簇与恶意簇之间时，HDBSCAN无法准确划分，会强行将其归入某一簇，导致误判。

​	本文 采用 DBSCAN 的密度聚类方式,**根据恶意客户端 数量不超过\(\dfrac{n}{2}\)的假设, **将数据点之间余弦距离的中位数作为Eps 领 域 半 径 的阈值并将 \(\dfrac{n}{2}\)作为  MinPts 簇内最小样本数目。该方法明确设置了领域半径和最小样本数目2个约束条件,每次聚类一个新梯度后,聚类圆心都会发生相应调整,每个梯度会根据密度距离关系被划分到最合适的簇中,**如果一 个梯度既可以分到 A 簇也可以分到 B 簇,该梯度  会被当作噪声点排除**，而非强行归类这恰好解决了HDBSCAN方案中恶意梯度的归属难题。

#### 自适应裁剪

​	自适应DBSCAN剔除了**角度偏离较大的恶意客户端**后,为进一步**削弱相近角度**中**被放大的恶意后门梯度**的影响,即攻击者在相近的角度上放大梯度。需要对高量级模型的梯度进行裁剪。现有的FLAME方案采用直接裁剪梯度大小的方法，但当**攻击者可以通过等比例缩放恶意梯度，使其欧氏距离与良性梯度之间的欧氏距离相近，从而逃逸裁剪**。

​	本文提出的方案中**先做TernGrad转化，再裁剪**：对客户端每轮训练后的梯度先进行TernGrad三元量化，该过程会提取每层梯度中绝对值最大的梯度作为该层的代表值，这相当于**放大了恶意梯度的幅值特征**。攻击者若试图通过等比例缩放来缩小恶意梯度、使其欧氏距离接近良性梯度，在TernGrad转化后，其每层的最大梯度值仍会显著偏离良性客户端的对应值，从而**无法逃逸后续的裁剪操作**。**裁剪边界自动设定**：裁剪半径 \(g_\alpha\)的选取至关重要，设小了会误删良性梯度，设大了压不住恶意攻击。本文沿用"恶意客户端不超过半数"的假设，**计算所有客户端梯度的二范数（即更新幅度），取其中位数作为裁剪边界**。幅度超过\(g_\alpha\)的被压缩回来，低于的保持不变，最大限度地保留良性梯度的完整性。

#### 自适应加噪

​	现有的实验表明通过加入差分隐私噪声可 以有效抵御异常样本的影响,在训练过程中给模型 添加适当的差分隐私噪声,有毒样本对模型的影响就会降低。适当的噪声使加噪后的梯度偏离恶意梯度而靠近良性梯度，选择合适的噪声水平\(\sigma\)是至关重要的,因为它直接影响良性模型的梯度有效性。\(\sigma\)太小：压不住残余后门，防御失败。\(\sigma\)太大：良性梯度被淹没，模型在主任务上的准确率大幅下降。

​	为解决 \(\alpha\)难以选取的问题，本文提出让\(\sigma\)与 的裁剪边界\(g_\alpha\)挂钩**。具体做法是：将神经网络各层的裁剪边界 \(g_\alpha\)作为差分隐私中的**敏感度 \(\Delta_2 f\)**，代入高斯机制公式计算每层的噪声强度：

​							\(\sigma = \dfrac{\Delta_2 f}{\varepsilon}\sqrt{2\ln\dfrac{1.25}{\delta}} = \dfrac{g_\alpha}{\varepsilon}\sqrt{2\ln\dfrac{1.25}{\delta}}\)

​	其中 \(\varepsilon\)（隐私预算）和 \(\delta\)（松弛因子）是差分隐私的预设常数，**真正决定 \(\sigma\)大小的是 \(g_\alpha\)**。
